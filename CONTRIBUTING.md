## 🚀 How to Get Listed

1. Fork the repository and create a feature branch.
2. Make your contribution: a new lab, a new vulnerability scenario, exercises, documentation, bug fixes, or translations.
3. Open a pull request with a clear description of your change.
4. Once merged, add yourself to the **Community Contributors** table in a follow-up commit, or ask the maintainer to add you.
